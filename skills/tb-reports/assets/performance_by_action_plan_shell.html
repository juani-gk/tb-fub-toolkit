What the labels mean

Each message carries every label that applies, worst news first. They're set against that plan's own average, so "high" means high for this drip, not high in the abstract. Definitions come from shared_pipeline.md §10 - keep this legend and that file in sync if the thresholds ever change.

High opt-outIts opt-out rate is well above the plan average, and not just noise at this volume.
More opt-outs than repliesIt loses more contacts than it earns conversations.
Low engagementIts reply rate is well below the plan average.
No repliesNobody replied, but some contacts did opt out.
Strong reply rateIts reply rate is well above the plan average.
Zero opt-outsEnough sends to matter, and nobody asked to stop.
In line with the planNothing stands out either way.
No response at allEnough sends to matter, not one reply and not one opt-out.
Not enough volumeBelow the response/volume floor, so nothing can be read into it.

How to read this

Step order is the position each message actually lands in for the average contact, measured across that automation's whole run rather than just the window shown. The number in the badge is the median position the message holds; the line under it is the typical gap since the previous message. Two messages sharing a number means the plan branches there, usually one variant per agent.
Not enough volume marks any message below this report's response/volume floor. It's still shown in sequence so the whole drip reads in order, but its numbers shouldn't be acted on.
Why two windows. %%WINDOW_RATIONALE%%
Replies are attributed to the last message sent before them, so a reply that arrives after a human or the AI assistant has already jumped into the thread counts against whichever of those sent last, not the original drip step.
